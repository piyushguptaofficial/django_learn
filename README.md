🔹 Project Setup
Installed Django and created a virtual environment.

Initialized Django project and app (core).

Registered app in settings.py.

🔹 Models, Migrations & Admin
Created models using Django ORM.

Ran makemigrations and migrate to apply DB schema.

Registered models in the Django admin panel for easy management.

Used render() to load HTML templates.

Passed data from views to templates using context.

🔹 URLs & Views
Created routes using urls.py.

Built function-based views (FBVs) to handle web pages.

🔹 Forms
Used forms.Form and forms.ModelForm.

Handled GET and POST requests with CSRF protection.
